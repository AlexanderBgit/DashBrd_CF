Навігація по дашбордуОсновні звіти F13 Forecast

  • f13w

    Головна оглядова сторінка дашборду F13 Forecast

    Для чого: швидкий огляд загального стану ліквідності та миттєвий доступ до основних звітів.

  • compare

    Порівняння прогнозів CF за різні періоди

    Для чого: графічне зіставлення поточного прогнозу з попереднім для виявлення та аналізу фінансових відхилень.

  • forecast

    Прогноз руху коштів на 13 тижнів

    Для чого: деталізовані статті за тижнями. Продовження звіту F13 Forecast.

  • analytics

    Інтерактивний звіт з бізнес-аналітики грошових потоків

    Для чого: візуалізація трендів надходжень і видатків за різні періоди, порівняння даних та оперативний контроль виконання бюджету.

Для департаменту бюджетуванняТрансформація F13 у помісячні формати

  • sop-home

    Показники грошового потоку помісячно

    Для чого: основні показники Казначейства у помісячному форматі для розрахунку грошових потоків непрямим методом.

  • sop-credit

    Кредити та постімпорт щомісячно

    Для чого: трансформація 13-тижневого прогнозу в помісячний рух коштів від фінансової діяльності.

  • rk-present

    Звіт про рух грошових коштів у форматі «РК-презентація»

    Для чого: трансформація 13-тижневого прогнозу у формат звіту РК-презентація.

Для аналітиків КазначействаВ розробці та налаштуванні

  • freecashв розробці

    Розрахунок і моніторинг вільного грошового потоку (FCF)

    Для чого: показники FCF, операційного та інвестиційного грошових потоків; оцінка здатності компанії генерувати чистий кеш після необхідних витрат.

  • liquidityв розробці

    Прогнозний звіт з ліквідності та платоспроможності

    Для чого: моделювання грошових потоків на 3–6 місяців для оцінки ризиків касових розривів і управління оборотним капіталом.

  • trendsв розробці

    Тренди ключових фінансових показників у довгостроковій перспективі

    Для чого: річна динаміка прибутковості та грошових потоків; допомагає виявляти сезонність і прогнозувати платежі.

  • forecast-rkв розробці

    Прогноз руху коштів АТ «Укрнафта» на 13 тижнів з мапінгом РК

    Для чого: корегування розрахунків у налаштованому звіті для департаменту бюджетування.

  • f13w-mв розробці

    Мобільна версія оглядової сторінки F13 Forecast

    Для чого: адаптація дашборду під смартфон — KPI та блоки в одну колонку, панель керування у вигляді нижньої шухляди, графік ліквідності розгортається на весь екран.

  • forecast-mв розробці

    Мобільна версія прогнозу руху коштів на 13 тижнів

    Для чого: адаптація деталізованої таблиці під смартфон — старт у форматі А3 з масштабуванням, компактна шапка й фільтри під кнопкою, гумовий режим із липкими заголовками.
